# 🐉 몬스터 카드 배틀 (학급용 팀전 카드 게임)

선생님이 방을 만들고, 학생들이 **학급 코드**를 입력해 참여하는 실시간 팀전 몬스터 카드 게임입니다.
크롬북을 포함해 **브라우저만 있으면** 설치 없이 플레이할 수 있어요.

- 👩‍🏫 **방장 = 선생님** : 방 만들기 → 6자리 학급 코드 표시 → 팀 배정 → 게임 진행
- 🎒 **학생** : 주소 접속 → 학급 코드 + 이름 입력 → 입장
- 👥 **팀전** : 2~4팀, 최대 **20명**
- 💻 **크롬북 지원** : 1366×768 화면 기준 설계, 터치 지원, 새로고침해도 자동 재접속

## 게임 규칙

1. **목표** : 상대 팀 기지 체력을 0으로 만들기. 마지막 라운드까지 가면 기지 체력이 가장 많은 팀이 승리.
2. **라운드** : 모든 학생이 동시에 카드 1장을 냄 (제한 시간). 모두 내면 바로 전투.
3. **마나 💎** : 1라운드 2개에서 시작해 라운드마다 +1 (최대 7). 카드 비용만큼 사용.
4. **몬스터** : 학생 1명당 전장에 몬스터 1마리. 새로 소환하면 교체.
5. **전투** : 모든 몬스터가 무작위 순서로 적 팀을 공격, 공격받은 몬스터는 반격. 적 전장이 비면 기지를 공격. 몬스터를 쓰러뜨리고 남은 피해는 기지로 **관통**.
6. **속성** : 🔥불 → 🌿풀 → 💧물 → 🔥불, ✨빛 ↔ 🌙어둠. 유리하면 피해 1.5배.
7. **특수 능력** : 도발 / 흡혈 / 돌격 / 광역 / 치유 / 단단함
8. **마법 카드** : 회복 물약, 성벽 수리, 힘의 룬, 파이어볼, 번개폭풍, 치유의 비, 운석 낙하
9. **패스** : 카드를 내지 않으면 카드를 1장 더 받음.

몬스터 25종 + 마법 7종, 모든 카드는 이 프로젝트용으로 새로 만든 오리지널입니다.

## 선생님 기능

- 팀 수 / 카드 내기 시간 / 라운드 수 / 자동 진행 설정
- 학생 팀 이동(◀ ▶), 팀 섞기, 내보내기(✕)
- 게임 중: 제출 현황 확인, `+15초`, `바로 전투`, `다음 라운드`, `게임 끝내기`
- 결과 화면: 우승 팀, 학생 활약 순위(피해량·처치·카드 수), `다시 하기`

## 실행 방법

Node.js 18 이상이 필요합니다.

```bash
npm install
npm start        # http://localhost:3000
npm test         # 게임 로직 시뮬레이션 테스트 (300판)
```

### 교실에서 쓰는 방법

**방법 1. 선생님 PC에서 실행 (같은 와이파이)**
1. 선생님 PC에서 `npm start`
2. PC의 IP 주소 확인 (예: `192.168.0.10`)
3. 학생 크롬북에서 `http://192.168.0.10:3000` 접속
   (학교망 방화벽이 3000번 포트를 막으면 방법 2 사용)

**방법 2. 무료 클라우드에 배포 (추천)**
[Render](https://render.com) 같은 Node.js 호스팅에 이 저장소를 연결합니다.
- Build Command: `npm install`
- Start Command: `npm start`
- 배포 후 나오는 주소(`https://xxxx.onrender.com`)를 학생들에게 알려 주면 됩니다.

> 게임 데이터는 서버 메모리에만 저장되며, 3시간 동안 활동이 없는 방은 자동으로 사라집니다.
