# 3jje — 볼 파이트 전투 시뮬레이터

웹: https://kangjjang150407-droid.github.io/3jje/

`index.html`을 브라우저(PC/모바일)로 열어도 실행됩니다. 이미지·효과음은 파일 안에 내장돼 있고, 배경음악은 `assets/bgm.mp3`를 사용해요.

- 캐릭터: **송재범**, **윤지호**, **강주원**, **과녁**
- 림버스 컴퍼니식 전투: 레벨, 공격/방어 레벨, 코인, 합, 정신력, 패닉, 출혈·진동·호흡·침잠·화상·충전·탄환 (1턴 = 5초)
- 송재범 2페이즈 **송재범 - [요루]**: 체력이 0이 되거나 뿡 적중 시 페이즈 변경
- 강주원 2페이즈 **강주원 [불타는 울음]**: 전장 복귀 시 페이즈 변경 (붉은 날개)
- 레드/블루 팀에 캐릭터를 추가하고 `▶ 시작`
- 배속(0.5x~4x), 일시정지(Space), 리셋
- 과녁 설정: 체력, 레벨, 이동 여부, 불사(사망 시 부활)
- 🧪 테스트 모드: 볼을 눌러 선택 → 체력·정신력·레벨·코카콜라·충전·탄환·상태이상 직접 수정, 스킬 강제 사용, 페이즈 변경, 패닉, 무적, AI 멈춤
- **전투 녹화**: `⏺ 녹화` 버튼, 또는 `전투 자동 녹화`(시작~승리 자동 녹화) → 미리보기 후 저장/공유
  - 모바일에서는 `📤 공유` → "동영상 저장"으로 갤러리/사진 앱에 저장할 수 있어요
- 효과음: 우나나 야하야하 음성, 공격 적중음(합성음) (툴바 🔊 버튼으로 음소거, 녹화에도 포함)
- 배경음악: 전투 시작 시 `assets/bgm.mp3` 반복 재생 (툴바 🎵 버튼으로 끄기). 로컬 파일로 열면 녹화 영상에는 배경음악이 안 들어가요
- 모바일: 세로 화면이면 아레나가 세로형으로 바뀌고, 게임 화면이 위에 고정돼요
