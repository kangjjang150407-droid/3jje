# 3jje — 볼 파이트 전투 시뮬레이터

`index.html` 하나만 브라우저(PC/모바일)로 열면 바로 실행됩니다. 이미지가 파일 안에 내장돼 있어요. (`assets/`는 원본 이미지)

- 캐릭터: **송재범**, **과녁**
- 레드/블루 팀에 캐릭터를 추가하고 `▶ 시작`
- 배속(0.5x~4x), 일시정지(Space), 리셋
- 과녁 설정: 체력, 이동 여부, 불사(사망 시 부활)
- **전투 녹화**: `⏺ 녹화` 버튼, 또는 `전투 자동 녹화`(시작~승리 자동 녹화) → 미리보기 후 저장/공유
  - 모바일에서는 `📤 공유` → "동영상 저장"으로 갤러리/사진 앱에 저장할 수 있어요
- 모바일: 세로 화면이면 아레나가 세로형으로 바뀌고, 게임 화면이 위에 고정돼요
